# Roof Wire

Overlay to-scale roof diagrams on drone photos of low-slope roofs, then save CoMo Premium Exteriors roof plan PDFs, edge metal drawings and material takeoffs.

Open the site in Chrome or Edge and click **Install** to add it to your desktop. On iPad or iPhone, open it in Safari, tap Share, then **Add to Home Screen**. It works offline after the first visit.

Jobs are saved on each device and are never uploaded here. Use **Job → Save project file** to move a job between devices.
